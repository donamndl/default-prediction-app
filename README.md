# 🚀 Default Prediction App

A full-stack web application that predicts loan default risk using both rule-based scorecards and machine learning.

---

## 📌 Features

* 📊 Credit scorecard evaluation
* 🤖 Machine learning-based prediction
* 📈 Dashboard analytics (approval levels, trends, stats)
* 🔐 Secure API handling
* 📦 MongoDB database integration

---

## ⚙️ Backend Setup (Flask)

```bash
cd backend
pip install -r requirements.txt
python app.py
```

Server runs on:

```
http://127.0.0.1:5000
```

---

## 💻 Frontend Setup (React + Vite)

```bash
cd frontend
npm install
npm run dev
```

Frontend runs on:

```
http://localhost:5173
```
